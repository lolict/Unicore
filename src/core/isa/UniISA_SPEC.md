# UniISA - 自主统一指令集架构
## Universal Instruction Set Architecture

### 核心理念

> **"不做别人的系统，做真正属于自己的指令集"**

---

## 一、架构设计

### 1.1 指令格式

```
UniISA 采用固定长度的三地址指令格式：

┌────────────────────────────────────────────────────────────┐
│  opcode (8bit) │ rd (8bit) │ ra (8bit) │ rb (8bit)     │
└────────────────────────────────────────────────────────────┘

扩展格式（用于立即数）：
┌────────────────────────────────────────────────────────────┐
│  opcode (8bit) │ rd (8bit) │ ra (8bit) │ 00 (8bit)    │
├────────────────────────────────────────────────────────────┤
│                    immediate (32bit)                      │
└────────────────────────────────────────────────────────────┘
```

### 1.2 寄存器模型

| 类型 | 数量 | 名称 | 说明 |
|------|------|------|------|
| 通用寄存器 | 64 | R0-R63 | 主要运算单元 |
| 向量寄存器 | 32 | V0-V31 | SIMD向量运算 |
| 控制寄存器 | 16 | C0-C15 | 系统控制 |
| 特殊寄存器 | 8 | PC/SP/HP/ZF/CF/OF/SF/PF | 状态标志 |

### 1.3 指令分类

#### A. 计算指令 (0x00-0x1F)

| 指令 | 编码 | 功能 |
|------|------|------|
| NOP | 0x00 | 空操作 |
| ADD | 0x01 | 加法: R[rd] = R[ra] + R[rb] |
| SUB | 0x02 | 减法: R[rd] = R[ra] - R[rb] |
| MUL | 0x03 | 乘法: R[rd] = R[ra] * R[rb] |
| DIV | 0x04 | 除法: R[rd] = R[ra] / R[rb] |
| MOD | 0x05 | 取模: R[rd] = R[ra] % R[rb] |
| NEG | 0x06 | 取负: R[rd] = -R[ra] |
| INC | 0x07 | 自增: R[rd]++ |
| DEC | 0x08 | 自减: R[rd]-- |

#### B. 位运算指令 (0x10-0x2F)

| 指令 | 编码 | 功能 |
|------|------|------|
| AND | 0x10 | 按位与 |
| OR | 0x11 | 按位或 |
| XOR | 0x12 | 按位异或 |
| NOT | 0x13 | 按位取反 |
| SHL | 0x14 | 左移 |
| SHR | 0x15 | 逻辑右移 |
| SAR | 0x16 | 算术右移 |
| ROL | 0x17 | 循环左移 |
| ROR | 0x18 | 循环右移 |
| BSWAP | 0x19 | 字节交换 |

#### C. 比较指令 (0x20-0x2F)

| 指令 | 编码 | 功能 |
|------|------|------|
| CMP | 0x20 | 比较: 设置标志位 |
| CMPEQ | 0x21 | 等于比较 |
| CMPLT | 0x22 | 小于比较 |
| CMPLE | 0x23 | 小于等于 |
| CMPGT | 0x24 | 大于比较 |
| CMPGE | 0x25 | 大于等于 |
| CMPNE | 0x26 | 不等于比较 |
| TEST | 0x27 | 位测试 |

#### D. 控制流指令 (0x30-0x3F)

| 指令 | 编码 | 功能 |
|------|------|------|
| JMP | 0x30 | 无条件跳转 |
| JZ | 0x31 | 零跳转 |
| JNZ | 0x32 | 非零跳转 |
| JE | 0x33 | 相等跳转 |
| JNE | 0x34 | 不等跳转 |
| JL | 0x35 | 小于跳转 |
| JLE | 0x36 | 小于等于跳转 |
| JG | 0x37 | 大于跳转 |
| JGE | 0x38 | 大于等于跳转 |
| CALL | 0x39 | 函数调用 |
| RET | 0x3A | 函数返回 |
| INT | 0x3B | 软件中断 |
| HALT | 0x3C | 停止执行 |

#### E. 内存指令 (0x40-0x4F)

| 指令 | 编码 | 功能 |
|------|------|------|
| LOAD | 0x40 | 加载: R[rd] = M[R[ra]] |
| STORE | 0x41 | 存储: M[R[rd]] = R[ra] |
| LOADB | 0x42 | 加载字节 |
| STOREB | 0x43 | 存储字节 |
| LOADH | 0x44 | 加载半字 |
| STOREH | 0x45 | 存储半字 |
| PUSH | 0x46 | 压栈 |
| POP | 0x47 | 弹栈 |
| LEA | 0x48 | 取地址 |

#### F. 向量/SIMD指令 (0x50-0x5F)

## 四、ABI调用约定

### 4.1 参数传递

| 参数位置 | 说明 |
|----------|------|
| R0-R7 | 前8个整型参数 |
| V0-V7 | 前8个向量参数 |
| R0 | 返回值 |
| R1 | 返回地址 |
| SP | 栈指针 |
| FP | 帧指针 |

### 4.2 调用过程

```
调用者:
1. 保存调用者保存的寄存器
2. 传递参数到R0-R7
3. 执行CALL指令
4. 回收返回值

被调用者:
1. 保存被调用者保存的寄存器
2. 分配栈帧
3. 执行函数体
4. 恢复寄存器
5. 执行RET返回
```

## 五、示例程序

### 5.1 Hello World

```assembly
; Hello World 程序
SECTION .data
    msg: DB "Hello, UniISA!", 0x0A, 0

SECTION .text
GLOBAL _start

_start:
    ; 加载字符串地址
    LEA R1, msg[R0]
    
    ; 写系统调用
    MOV R7, 1        ; sys_write
    MOV R0, 1        ; stdout
    MOV R2, 14       ; length
    SYSCALL
    
    ; 退出系统调用
    MOV R7, 60       ; sys_exit
    MOV R0, 0        ; exit code
    SYSCALL
```

### 5.2 斐波那契数列

```assembly
; 斐波那契数列计算
SECTION .text
GLOBAL fib

fib:
    CMP R0, 1
    JLE base_case
    
    ; fib(n-1)
    PUSH R0
    DEC R0
    CALL fib
    POP R1
    
    ; fib(n-2)
    PUSH R0
    SUB R0, 2
    CALL fib
    POP R1
    
    ; return fib(n-1) + fib(n-2)
    ADD R0, R0, R1
    RET

base_case:
    MOV R0, 1
    RET
```

## 六、兼容性

### 6.1 二进制翻译接口

UniISA提供二进制翻译框架，支持将以下指令集翻译为UniISA：

| 源指令集 | 翻译状态 |
|----------|----------|
| x86/x64 | 支持 |
| ARM v7/v8 | 支持 |
| RISC-V | 支持 |
| MIPS | 支持 |
| MIPSEL | 支持 |
| PowerPC | 支持 |

### 6.2 翻译过程

```
源程序 (x86/ARM/RISC-V)
         │
         ▼
    ┌─────────────┐
    │  指令解码   │
    └─────────────┘
         │
         ▼
    ┌─────────────┐
    │  语义分析   │
    └─────────────┘
         │
         ▼
    ┌─────────────┐
    │ UniISA生成  │
    └─────────────┘
         │
         ▼
    UniISA字节码
```
