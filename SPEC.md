# UniCore - 统一智能核心系统

## 项目愿景

> "创造一个没有平台之别、没有硬件束缚的统一计算系统"

## 核心理念

- **统一时序**: 所有操作在同一时间维度完成
- **统一能力**: 一个核心拥有所有功能
- **统一关系**: 所有平台共享同一运行时
- **无依赖**: 不依赖任何特定环境

## UniISA 统一指令集

### 核心指令分类

| 类别 | 指令 | 说明 |
|------|------|------|
| 计算 | `ADD`, `SUB`, `MUL`, `DIV`, `MOD` | 算术运算 |
| 逻辑 | `AND`, `OR`, `NOT`, `XOR`, `SHL`, `SHR` | 位运算 |
| 控制 | `JMP`, `JZ`, `JNZ`, `CALL`, `RET` | 流程控制 |
| 内存 | `LOAD`, `STORE`, `ALLOC`, `FREE` | 内存操作 |
| 并行 | `SPAWN`, `SYNC`, `SEND`, `RECV` | 并发操作 |
| AI | `INFER`, `EMBED`, `TOKENIZE` | AI推理 |
| 多媒体 | `PLAY`, `RENDER`, `CAPTURE` | 媒体处理 |

### 指令格式

```
┌────────────────────────────────────────────┐
│  opcode (8bit) │ operands... (可变)        │
└────────────────────────────────────────────┘
```

## 平台适配

| 平台 | 运行时 | 大小 | 说明 |
|------|--------|------|------|
| Android | Wasmtime-Android | ~5MB | APP安装包 |
| ESP32 | wasm3-micro | ~50KB | 固件烧录 |
| Windows | Wasmtime | ~10MB | EXE程序 |
| macOS | Wasmtime | ~10MB | APP程序 |
| Web | 原生WASM | 0KB | 直接浏览器运行 |
| Linux | Wasmtime | ~10MB | 可执行文件 |

## 开发路线图

1. **Phase 1**: 核心指令集 + Zig运行时
2. **Phase 2**: Rust安全包装 + WASM编译
3. **Phase 3**: Go并发加速 + 网络服务
4. **Phase 4**: Python AI层 + 推理引擎
5. **Phase 5**: 协议层 + Agent通信
6. **Phase 6**: 工具集 + 多媒体处理
7. **Phase 7**: 多平台打包
